Интеграции

«Планёрка» подключается к Telegram, Google Календарю, Slack и GitHub.
Telegram-бот присылает уведомления о новых задачах и упоминаниях. Подключение: Профиль → Интеграции → Telegram.    
Синхронизация с Google Календарём односторонняя: сроки задач появляются в календаре, но изменения в календаре обратно не переносятся.



Вебхуки доступны только на тарифе «Бизнес» и выше.
Публичный API ограничен 60 запросами в минуту на один токен. При превышении API возвращает код 429, повторить запрос можно через минуту.
